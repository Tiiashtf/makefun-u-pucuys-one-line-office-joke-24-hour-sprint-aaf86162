Entry for the make.fun bounty
[One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162):
a program that writes one funny single-line joke about office life, under
200 characters, to `/output/entry.txt`.

## The line

> We switched to hot-desking, so now I start every morning by reintroducing myself to my own chair.

97 characters — inside the 1–200 character gate.

The joke is one idea: hot-desking turned the office into a place where even
your own chair is a stranger every morning.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt`. Deterministic: every run writes the
same bytes. No network access.
